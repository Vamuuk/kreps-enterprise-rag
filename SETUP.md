# KREPS RAG System - Setup Instructions

## Terminal Commands

### 1. Navigate to Project Directory

```bash
cd kREPS-rag
```

### 2. Create Virtual Environment (Python 3.10+)

**Windows:**
```bash
python -m venv .venv
.venv\Scripts\activate
```

**Linux/Mac:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install Dependencies

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Verify Installation

```bash
python src/app.py status
```

Expected output:
```
============================================================
KREPS RAG SYSTEM - STATUS
============================================================

✗ Chunks: Not found
✗ FAISS index: Not found
✗ BM25 index: Not found

Run indexing: python src/app.py index
```

### 5. Add Test Documents (Optional)

Create a sample document for testing:

**Windows:**
```bash
echo "Safety Procedures: Always follow emergency protocols. Regular inspections are mandatory." > data\raw_docs\test.txt
```

**Linux/Mac:**
```bash
echo "Safety Procedures: Always follow emergency protocols. Regular inspections are mandatory." > data/raw_docs/test.txt
```

Or copy your existing documents:

**Windows:**
```bash
copy path\to\your\docs\*.pdf data\raw_docs\
```

**Linux/Mac:**
```bash
cp path/to/your/docs/*.pdf data/raw_docs/
```

### 6. Build Indices

```bash
python src/app.py index
```

**Expected Output:**
```
============================================================
KREPS RAG SYSTEM - INDEXING
============================================================

[1/4] Ingesting documents...
✓ Ingested X document pages/sections

[2/4] Chunking documents...
✓ Created X chunks

[3/4] Building FAISS semantic index...
NOTE: This requires Qwen embedding model integration
⚠ FAISS indexing skipped (Qwen embeddings not integrated)
  The system will use BM25 lexical search only
  To enable semantic search, integrate Qwen in src/embed.py

[4/4] Building BM25 lexical index...
✓ BM25 index built successfully

============================================================
INDEXING COMPLETE
============================================================
```

### 7. Test Query

```bash
python src/app.py query "What are the safety procedures?"
```

## Important Notes

### Virtual Environment

- **ALL code is OUTSIDE .venv/** ✓
- .venv/ contains only Python packages
- Never modify files inside .venv/

### Code Location

- All project code is in `src/`
- All configuration in `src/config.py`
- No code in root directory except CLI entry point

### Next Steps After Setup

1. **Test with sample data** - Verify indexing and retrieval work
2. **Integrate Qwen embeddings** - Enable semantic search (see README.md)
3. **Integrate Qwen LLM** - Enable answer generation (see README.md)
4. **Tune parameters** - Adjust chunk size, retrieval weights in config.py
5. **Add production documents** - Replace sample data with real docs

## Troubleshooting

### "No module named X"

```bash
pip install -r requirements.txt
```

### "Documents directory does not exist"

```bash
# Windows
mkdir data\raw_docs

# Linux/Mac
mkdir -p data/raw_docs
```

### "Index not found"

```bash
python src/app.py index
```

### Python version issues

Requires Python 3.10+:

```bash
python --version
```

If version is too old, install Python 3.10+ and recreate venv.
